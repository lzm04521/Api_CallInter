# ApiCallInter

Windows 桌面常驻的 API 定时保活工具：托盘程序 + 本机 Web 管理页，按项目级固定间隔定时调用配置的 HTTP 接口，记录每次请求结果，支持应用内自升级。

## 项目简介

- **定时调用**：项目级间隔秒数 + 毫秒级随机抖动（±）打散执行；启动即执行一轮，之后按间隔循环，错过不补发；支持手动"立即请求"。
- **托盘常驻**：开机自启、单实例，双击托盘图标打开管理页。
- **Web 管理页**：概览（版本/内存/下次调度）、项目管理、请求日志、系统设置、关于，五页面。
- **自升级**：关于页检查 GitHub Release 新版本，一键升级（下载 → 校验 → 自动重启替换）。
- **绿色部署**：发布为自包含单目录程序，解压即用，无需安装 .NET 运行时。

## 首次安装

1. 从 [Releases](https://github.com/lzm04521/Api_CallInter/releases) 下载 `ApiCallInter-win-x64.zip`。
2. 解压到任意目录（如 `D:\Tools\ApiCallInter`）。
3. 双击 `ApiCallInter.exe`，托盘出现图标。
4. 托盘右键菜单勾选**开机自启**（写入当前用户注册表 Run 项）。

## 日常使用

1. 双击托盘图标（或右键 → 打开管理页）打开 `http://127.0.0.1:61121`。
2. **项目管理**：新建项目与接口（项目设间隔秒数与随机抖动；接口设 URL、方法、请求头、请求体等），可对单个接口"立即请求"验证。
3. **概览**：查看运行时长、内存、下次调度时间；**请求日志**：查看每次调用的状态码、耗时、错误信息。

## 升级

- **一键升级**：管理页"关于"页 → 检查更新 → 有新版本时点"一键升级"，程序自动下载 zip、校验、重启完成替换，全过程写 `logs\update.log`，失败不影响当前版本运行。
- **手动升级**：下载新版 `ApiCallInter-win-x64.zip`，退出程序后解压覆盖原目录，再启动即可。

## 数据与排障

所有数据存于 `%ProgramData%\ApiCallInter\`（可用环境变量 `APICALLINTER_DATA_DIR` 覆盖到其他目录）：

| 路径 | 说明 |
|---|---|
| `app.db` | SQLite 数据库（项目、接口、请求日志、系统设置） |
| `logs\app-*.log` | 主程序日志（按天滚动，保留 30 天） |
| `logs\bootstrap-*.log` | 启动早期日志 |
| `logs\update.log` | 升级过程日志 |

常见问题：接口不通检查请求日志中的错误信息；管理页打不开确认端口未被占用；升级异常看 `update.log`。

## 端口

默认监听 `http://127.0.0.1:61121`。修改方式：管理页"系统设置"中修改端口并保存，**需重启程序后生效**（设置页有"立即重启程序"按钮，重启后用新端口访问）。

## 安全声明

本工具**无任何鉴权**，管理页与 API 仅限本机或可信内网使用，请勿暴露到公网。
